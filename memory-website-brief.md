# Example request — fictional material

Use `$interactive-memory-website` to plan an anniversary website for two fictional people, Alex and Sam.

Inputs: six synthetic couple photos with matching character stickers, three gift illustrations and four future travel wishes. No real photographs or private correspondence are supplied.

Direction: a cozy home with warm lighting, varied soft colors and a rounded English display title. Keep real-photo framing intact; keep decorative stickers static. Future wishes must not look like documented past travel.

Process: first present two distinct concepts in text. After I choose one, make representative home, album and gift views. Wait for confirmation before implementing. Work in a local copy; do not publish.

Expected planning output:
- Media inventory and unresolved choices.
- A single coherent spatial concept and a compact visual system.
- Album order and source rectangles for selected sticker poses.
- State plan for gifts and failure handling for photo loads.
- Local preview acceptance checks and an explicit distinction between a concept image and an implemented interaction.

This brief can be used for a first independent trial. Keep the trial's actual outputs and failures before claiming that the skill has been behaviorally validated.
