# Skill Portfolio

把真实创作任务整理成可复用的 AI 工作流。

本作品集目前包含 **1 个技能初稿**：从互动纪念网站的设计与迭代中，提炼内容规划、素材映射和交互状态处理方法。使用 AI 辅助编写和整理，人工需求与审美判断来自创作过程。

## 如何使用

下载本仓库，将 `skills/interactive-memory-website` 整个文件夹放入你的 AI 工具支持的技能目录。在 Codex 中，通常是用户目录下的 `.codex/skills/`。之后在新回合中调用：

```text
用 $interactive-memory-website 设计一个周年纪念网站。
我有六张合照与三件礼物，希望先看文字方案和关键静态画面，
确认后只在本地副本里制作交互预览。
```

也可以直接让支持读取本地文件的 AI 阅读该文件夹中的 `SKILL.md` 后执行。技能不会自动安装工具、下载模型或发布网站。

## 作品的边界

- 技能提供执行流程与判断标准，不是完整的网站生成器，也不附送图像或音乐生成服务。
- 本仓库未包含真人照片、私人信件、真实收件人姓名、账号信息或原网站部署包。
- 展示案例经过文字匿名化，没有复制第三方角色图片或其他作者的技能内容。
- 不宣称跨模型效果一致。当前仅完成文件结构和链接检查，独立应用效果仍需验证。
